# SST-2 Sentiment Analysis ML Project

This repository contains the reduced version of a sentiment analysis project submitted for a Machine Learning examination. The project focuses on analyzing the Stanford Sentiment Treebank (SST-2) dataset, implementing various machine learning techniques for sentiment classification.

## Project Structure

- **src/**: Source code for the sentiment analysis pipeline
  - `01_data_loading.py`: Downloads and processes the SST-2 dataset from Hugging Face
  - `02_preprocessing.py`: Text preprocessing including tokenization, cleaning, and normalization
  - `03_feature_engineering.py`: Feature extraction including BOW, TF-IDF, and embeddings
  - `04_model_analysis.py`: Model training, evaluation, and analysis with learning curves
  - `utils.py`: Utility functions for data handling and visualization

- **data/**: Contains raw and processed datasets
  - `raw/`: Original SST-2 dataset
  - `processed/`: Preprocessed and feature-engineered data

- **runs/**: Experiment logs and model outputs

- **ML_project_report.pdf**: Detailed report on the project methodology and findings

## Project Features

- Dataset analysis and preprocessing for sentiment classification
- Implementation of classical ML algorithms
- Model analysis with learning curves and validation metrics
- Comprehensive evaluation of algorithm performance
- Visualization of model insights and comparative analysis

## Requirements

- Python 3.6+
- pandas
- scikit-learn
- matplotlib
- datasets (Hugging Face)
- numpy

## Usage

1. **Data Loading**:
   ```
   python src/01_data_loading.py
   ```

2. **Preprocessing**:
   ```
   python src/02_preprocessing.py
   ```

3. **Feature Engineering**:
   ```
   python src/03_feature_engineering.py
   ```

4. **Model Analysis**:
   ```
   python src/04_model_analysis.py
   ```
